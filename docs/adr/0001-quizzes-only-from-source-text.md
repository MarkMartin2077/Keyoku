# Quizzes are generated only from a deck's source text

A quiz's questions, answers and explanations come only from the deck's source text, never from the model's own knowledge, so hand-made decks (no source text) can't be quizzed. We chose this over free-topic quizzes and over building quizzes from a deck's cards because Keyoku's promise is "study your material, not the model's": source text gives every answer something to be checked against, while topic quizzes invite confident hallucinations.

## Considered Options

- **Free-topic quizzes** (as in the Questionable tutorial): rejected; a different product with no source to check answers against.
- **Quizzes built from a hand-made deck's cards** (card answer as the correct answer, model writes the wrong answers): deferred, not rejected. It's the natural way to let hand-made decks have quizzes later.
